# ⚡ Premium Platform

A full-featured **Laravel 12** content monetization platform where Creators publish free & premium content, Readers pay to unlock it, and Admins manage everything.

---

## 🚀 Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | Laravel 12 |
| Auth | Laravel Breeze |
| Roles & Permissions | Spatie Laravel Permission |
| Payment (International) | Stripe |
| Payment (Bangladesh) | SSLCommerz |
| Queue & Jobs | Laravel Queue (Database) |
| Notifications | Laravel Notifications |
| Email Testing | Mailtrap |
| Frontend | Blade + Tailwind CSS |
| Database | MySQL |

---

## 👥 Roles

### 👑 Admin
- View all users, assign/change roles
- Activate / deactivate users
- View all posts and payments
- Full role & permission management

### ✍️ Creator
- Create free & premium posts
- Set price for premium content
- Edit / delete own posts
- View earnings

### 📖 Reader
- Browse all published posts
- Read free posts immediately
- Pay to unlock premium posts (Stripe or SSLCommerz)
- Notification bell for alerts
